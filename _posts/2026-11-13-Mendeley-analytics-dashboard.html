--- title: "Mendeley Analytics Dashboard: Automated Bibliometric & Topic Analysis" created_at: 2026-11-13 14:36:00 EST author: Mohamed Abuella layout: post ---

This project presents an interactive dashboard that analyzes a Mendeley reference library directly in the browser. It reads a standard BibTeX export, extracts bibliometric fields, and applies TF-IDF text mining and topic clustering to reveal the main research themes, following the workflow of Abuella (2024), Automating Academic Document Analysis with ChatGPT: A Mendeley Case.

Interactive Dashboard

The dashboard loads the latest .bib file from its repository automatically. You can explore word clouds, publication trends by year, document type, venue and author, discovered topic clusters and their evolution, and a searchable document table, all with PNG, PDF, TXT and CSV exports:
