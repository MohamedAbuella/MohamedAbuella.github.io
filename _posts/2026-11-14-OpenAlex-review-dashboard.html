This project presents an interactive, browser-based dashboard that queries the open OpenAlex scholarly database to collect, analyze, and synthesize academic literature in real time. Using Boolean search operators and metadata filters (author, affiliation, venue, country, work type, and citation threshold), it performs bibliometric profiling, TF-IDF and n-gram text mining, abbreviation extraction, and Latent Dirichlet Allocation (LDA) topic modeling, ranking the most aligned papers for instant export as a clean .bib database.

Interactive Dashboard

Enter a search query or apply advanced metadata filters to fetch relevant works with abstracts and citation counts directly from the OpenAlex API. Across five interactive views, you can inspect top journals, leading authors, yearly publication trends, annual citation outliers (via the 1.5×IQR rule), TF-IDF terms, bigrams, extracted abbreviations, word correlations, customizable LDA topic clusters, and an alignment-ranked literature table with one-click .bib download:
